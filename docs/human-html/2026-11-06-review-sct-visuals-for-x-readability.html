What fails at phone size

The main issue is information density, not export resolution. The other-tools PNGs are 2800 × 2100, exported from a 1400-pixel-wide layout. An 18-pixel chart label becomes about 5 pixels at a 390-pixel display width. More export pixels do not make the label larger on screen.

Metric definitions and tested version must survive reduction. Full versus shared entity coverage, matching documents within pairs, and uncertainty are essential to the conclusion. The viewer should not need to open the report to discover that a headline has a narrower scope.

The plots have honest intervals, a zero reference and direction labels. Those help a technical reader. Fourteen rows and a subtraction axis still demand sustained attention. The tradeoff chart adds a second panel whose better direction reverses.

A better sequence for this post

Images 3 and 4: what the benchmark found. Give shared-type and full-taxonomy recall separate cards. Make the tested version, synthetic-data scope and default configuration prominent. If showing a subset of tools, state the selection rule and link all results.
