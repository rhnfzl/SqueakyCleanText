1. Processing pipeline

Image description for X

SqueakyCleanText is a configurable text-processing pipeline. Four stages: detect language, repair text, handle personal data, then score and document. PII is one stage. Outputs include cleaned text and signals, with optional scoring and data cards. Stages can be switched off.

2. PII routing

Full-resolution PNG · Editable source

Image description for X

SCT's PII stage combines its own regex rules with a chosen model backend. Rules cover emails, phones, IPs, IBANs, cards and custom patterns. Supported backend choices include ONNX, PyTorch, GLiNER, GLiNER2 and beta Presidio plus GLiNER. Language-based model selection and custom models use documented interfaces. These are configurable choices, not simultaneous use of all backends or integration of every benchmarked tool.

Post 1

SqueakyCleanText is a text-processing pipeline for training and RAG datasets. Language detection, text repair, PII handling, scoring and data cards. I benchmarked its PII stage alongside other tools: 18 entries, 12 datasets. Tested SCT version: v0.8.2.

Post 2

The PII stage also acts as a router. SCT has its own regex detection and language-based model routing. You can choose supported backends and models: ONNX, PyTorch, GLiNER, or Presidio/GLiNER. The pipeline is not tied to one detection model.

Post 3

On shared emails, phones and numbers, four tools have higher masking recall than SCT default: PII-Tracer, BardsAI-v3, OPF and OpenMed. These are synthetic-data, matched-document comparisons. The image shows every pair whose 95% interval favours the other tool.

Post 4

Across the broader label set, SCT default has higher recall in 13 of 14 paired synthetic comparisons. The GLiNER2-Fastino interval crosses zero. Unsupported types count as misses, so this also measures entity coverage. Intervals are unadjusted.

Post 5

One example: PII-Tracer has higher masking precision than SCT on the same synthetic data, 78.1% vs 75.0%. These are dataset averages. Precision counts predicted mask spans that overlap a labelled mention. It is a separate measure from recall.

Post 6

In that same pair, SCT has higher recall, but its document-exposure rate is higher: 58.0% vs 50.2%, averaged across datasets. Recall counts any overlap. A partly masked identifier can still leave sensitive letters or digits visible.

Post 7

This benchmark tests PII configurations, not the whole processing pipeline. It tested v0.8.2. v0.8.3 is available, but these results do not measure it. Full methods, limits and results: https://github.com/rhnfzl/SqueakyCleanText/blob/main/benchmarks/results/compare-2026-11-04/README.md

Evidence and limits

The card generator reads the archived round-2 summary through the existing validated extractor. It preserves source values and the aggregate SHA-256. No benchmark inference is rerun.

The shared-type card includes all four non-SCT tools whose paired recall advantage has a recorded 95% interval entirely above zero. The full-taxonomy card counts 13 higher-SCT intervals, one crossing zero and none below zero. Those intervals have no multiple-comparison correction.

Precision and exposure show one named pair, SCT default and PII-Tracer, on the same synthetic documents. Values are dataset averages, not pooled document percentages. DATE is excluded. Masking recall counts any overlap; exposure checks whether a labelled letter or digit remains visible.

Different tool pairs can use different clean dataset/language subsets. SCT receives gold language. The benchmark does not test automatic language selection or the complete processing pipeline end to end.

The available release is v0.8.3. This other-tools benchmark tests v0.8.2. These results do not establish the later version’s ranking.
