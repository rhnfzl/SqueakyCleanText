## F1: framework adapters (decisions 7, 8, 14, 15)

### Added
- `sct.integrations.hf.clean_dataset` (+ `SCTMap`) for Hugging Face `datasets` (`Dataset` and `IterableDataset`), `score=True` adds the `sct_*` score columns.
- `sct.integrations.datatrove.SCTCleaner` DataTrove step; counts `pii`, `pii_<TYPE>`, `sensitive` stats.
- `sct.integrations.langchain.SCTDocumentTransformer` and `sct.integrations.haystack.SCTDocumentCleaner`.
- `sct.integrations._runtime.CleanerHandle` / `clean_columns` / `clean_records`: one cleaner per adapter per process, rebuilt on PID change, pickles as config only. No global cleaner.
- Shared options: `columns` (default the main text field), `output="overwrite"` (default) or `"new_column"` (`<col>_clean`, raw kept), `config` (default `"training"` preset; reversible mode rejected). Document adapters write `metadata["sct"]` = public signals of the first column.
- `docs/INTEGRATIONS.md`, `docs/RECIPES.md` (Ray, Spark, Polars, DuckDB, dlt, Daft; Polars and DuckDB run by hand).
