## F4: multilingual PII eval set

- New `evaluation/multilingual_pii.jsonl`: 220 synthetic records, 20 each for en, nl, de, es, zh, ja, th, ar, hi, bn, ta, built by `scripts/build_multilingual_eval.py` (deterministic; spans from slot insertion).
- New `scripts/run_multilingual_eval.py`: scores the default ensemble and GLiNER multilingual models per language and label; results in `evaluation/results/multilingual-2026-10-31.json`, write-up in `docs/MULTILINGUAL_EVAL.md`.
- Result: default ensemble 0.84 recall / 0.89 precision overall, ahead of GLiNER multi v2.1 (0.45 / 0.68) and GLiNER multi PII v1 (0.57 / 0.91). Default model not switched.
- Found (not fixed here, core follow-ups): email regex swallows glued CJK text and the Arabic comma; phone numbers with a space between digit groups are cut short.
